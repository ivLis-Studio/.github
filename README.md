# ivLis Studio community files

This repository holds the default community health files for [ivLis Studio](https://github.com/ivLis-Studio) repositories. GitHub shows them in every repository that does not have its own copy.

| File | Purpose |
|---|---|
| [CONTRIBUTING.md](CONTRIBUTING.md) | How to contribute to the Android, iOS, Overlay, and Helper repositories. ivLyrics for PC has its [own guide](https://github.com/ivLis-Studio/ivLyrics/blob/main/CONTRIBUTING.md). |
| [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) | Expected behavior in issues, pull requests, and Discord. |
| [SECURITY.md](SECURITY.md) | How to report vulnerabilities privately. |
| [ISSUE_TEMPLATE/](ISSUE_TEMPLATE) | Bug report and feature request forms. |
| [PULL_REQUEST_TEMPLATE.md](PULL_REQUEST_TEMPLATE.md) | The checklist shown when opening a pull request. |

ivLyrics projects are source-available under the ivLyrics Source-Available License 1.0. Each repository's `LICENSE` and `NOTICE.md` have the exact terms.
